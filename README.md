# Flipkart Sales Analysis – Power BI

## Project Overview
This project focuses on analyzing Flipkart sales data using Microsoft Power BI. The dashboard provides insights into sales performance, profit, product categories, and business trends.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Excel
## Dashboard Overview

The Flipkart Sales Analysis dashboard provides an interactive view of sales performance and business trends.

The dashboard includes:

- **Sales Performance:** Analysis of overall sales and profit.
- **Product Analysis:** Category and sub-category performance.
- **KPI Cards:** Total Sales, Total Profit, Total Quantity and Total Orders.
- **Date Analysis:** Order Date and Year slicers to explore sales across different periods.
- **Interactive Visualizations:** Charts and graphs to understand business performance.

The dashboard helps identify sales trends, evaluate product performance and gain meaningful business insights.
## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Quantity
- Total Orders

## Dashboard Features
- Interactive sales dashboard
- Product category and sub-category analysis
- Sales and profit performance tracking
- Interactive filters and slicers
- Data visualization using charts and KPI cards

## Project Objectives
- Analyze overall sales performance.
- Identify top-performing product categories.
- Understand profit trends.
- Support data-driven business decisions.
