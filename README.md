# Flipkart Sales Analysis – Power BI

## Project Overview
This project focuses on analyzing Flipkart sales data using Microsoft Power BI. The dashboard provides insights into sales performance, profit, product categories, and business trends.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Excel

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Quantity
- Total Orders

## Dashboard Features
- Interactive sales dashboard
- Product category and sub-category analysis
- Sales and profit performance tracking
- Interactive filters and slicers
- Data visualization using charts and KPI cards

## Project Objectives
- Analyze overall sales performance.
- Identify top-performing product categories.
- Understand profit trends.
- Support data-driven business decisions.
